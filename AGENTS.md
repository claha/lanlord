# lanlord

Self-hosted LAN device inventory for homelabs: an ARP scanner with a web UI.
Rust 2024, single crate, built and deployed with Nix.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `claha/lanlord`, driven by the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, with label strings identical to their names. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` at the root, decisions in `docs/adr/`. See `docs/agents/domain.md`.
